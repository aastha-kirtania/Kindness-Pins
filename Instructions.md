# Kindness Pins 🌸

A location-based message-sharing app built with **Next.js**, **React Leaflet**, and **Supabase**. Users can leave pins with messages at specific locations, and nearby users receive notifications when they enter the pin’s radius.

---

## Demo
Access the deployed app here: https://kindness-pins.vercel.app

---

## Features
- Drop pins on the map with a custom message and visibility radius.
- Real-time updates: messages appear instantly for all users.
- Notifications when entering a pin’s radius.
- Auto-centers map on your location.
- Delete pins you added.

---

## Tech Stack
- **Next.js** – React framework for server-side rendering.
- **React Leaflet** – Interactive map interface.
- **Supabase** – Backend database & real-time updates.
- **TypeScript** – Type safety.
- **React Hot Toast** – Notifications.
